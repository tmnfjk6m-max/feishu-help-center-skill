## 飞书People
### 出自《工资单常见问题》
原文：https://www.feishu.cn/hc/zh-CN/articles/791669014160-工资单常见问题

- **Q：我上传的数据会被其他的工资单管理员看到吗？**
  A：所有数据仅会对具有相应权限的工资单管理员公开。
- **Q：工资单 Excel 表格上传失败了怎么办？**
  A：可以下载错误文件，文件中将标明错误项，并附上错误原因。按照要求修改后再上传即可。
- **Q：工资单Excel表格上传格式要求是什么？**
  A：工资单上传时要确保 Excel 工资表中包含“姓名”和“实发金额”两项。 同时要确保 Excel 工资表中至少包含“手机号”或“邮箱”中的任意一项。 工资单中的“姓名”“手机号”“邮箱”等字段将会与飞书管理后台的企业通讯录中的信息进行对比，请确保填写的为正确信息。 工资单支持自定义添加其他薪资项目。
- **Q：可以修改工资单的 Excel 模板吗？**
  A：可以。工资单 Excel 模板支持自定义，除了姓名、邮箱、实发金额是必填项，其他项可以根据需要增加或者删除。
- **Q：工资单可以不展示为“ 0”或“空”的工资项吗？**
  A：可以。在显示设置中，可以选择隐藏为空的或者金额为0的工资项。
- **Q：如何为工资单添加备注说明？**
  A：在设置并发布中，可以添加附加说明，添加所需备注的信息。
- **Q：不小心发错工资单怎么办？**
  A：管理员可以撤回该员工工资，编辑后重新发送。
- **Q：提示“该员工不在权限范围内”怎么办？**
  A：管理员仅能对自己权限范围内的人员工资单进行上传发放和查看管理操作，若需修改权限范围，请联系系统管理员。
- **Q：上传工资单时看到错误提示“邮箱与姓名不匹配”怎么办？**
  A：需要管理员核对邮箱与姓名是否与飞书管理后台一致，注意不要将员工的个人邮箱填写至企业邮箱处。
- **Q：上传工资单时看到错误提示“手机号不在企业通讯录中”怎么办？**
  A：需要管理员核对手机号是否与飞书管理后台一致，或在飞书管理后台检查该人员是否在工资单应用“可用性状态”范围内。启用工资单应用后，需要设置接收工资单的人员的范围，一般选择“全体成员”。
- **Q：已经离职了，可以查看工资单吗？**
  A：不可以，详情可咨询企业内 HR。
- **Q：如果早前的工资单管理员已因故被移除（如离职或调岗），现在需要重新添加其他人为工资单管理员，但在页面上没有出现设置按钮，应当如何处理？**
  A：请工资单系统管理员进行添加。如在重新添加工资单管理员过程中需要区分不同角色的权限，请参考工资单功能使用手册。
- **Q：某离职员工是唯一的系统管理员和工资单管理员，公司是否有方法收回该离职员工的权限并让其他人进入工资单的管理后台？**
  A：飞书企业管理员重新分配系统管理员和工资单管理员，删除该离职员工的权限。
- **Q：可以上传中英版本的工资单吗？**
  A：除了姓名、邮箱、实发金额必填项无法修改以外，其他自定义项可以直接在表头附加上英文名称。
- **Q：工资单管理员转移权限给他人时，要转移哪些权限？**
  A：只有拥有工资单管理员权限的人员可查看、发送、管理人员工资单。若工资单管理员和超级管理员为同一人时，需同时转移 2 个权限，不可只转移超级管理员的权限。若超级管理员无法进入工资单管理后台，请联系页面显示的联系人（工资单应用的系统管理员）添加相关权限。
- **Q：工资单限时查看时效设置完成并保存成功，会影响已发送工资单吗？**
  A：不会。不会影响设置前的已发送和发送中的工资单，仅对设置并保存成功后发送的工资单生效。
- **Q：员工从哪个入口会触发工资单限时查看倒计时？**
  A：限时查看开启后，员工访问发送的工资单详情页均会触发，例如工资单列表或者飞书通知。
- **Q：工资单确认设置完成并保存成功，会影响已发送工资单吗？**
  A：不会。不会影响设置前的已发送和发送中的工资单，仅对设置并保存成功后发送的工资单生效。
- **Q：在设定的确认截止时间前，仍未确认工资单的员工会收到催办提醒吗？**
  A：不会。目前暂不支持给员工发送催办通知。
- **Q：员工进入什么页面会触发工资单确认按钮和工资单确认倒计时？**
  A：工资单确认功能开启后发送，只要员工进入发送的工资单，即会展示确认按钮及倒计时。
- **Q：设置确认时效时可以设置非整数吗？**
  A：不可以。输入非整数后，系统会自动对所输入的非整数进行四舍五入。

### 出自《飞书人事标准版管理员使用手册》
原文：https://www.feishu.cn/hc/zh-CN/articles/360049068032-飞书人事标准版管理员使用手册

- **Q：飞书人事（标准版）不同的权限有什么区别？**
  A：飞书人事管理员拥有飞书人事（标准版）的全部权限，人事子管理员只拥有被授权的功能和权限。员工只能在飞书人事（标准版）的移动端里，依照管理员的设置，查看/编辑员工本人的详情页资料，发起飞书人事（标准版）相关的审批。
- **Q：在飞书通讯录和飞书人事（标准版）之间，哪些员工信息会自动更新？**
  A：飞书组织架构中的成员信息、工作信息及部门中的飞书系统默认字段（例如：姓名、电话、邮箱、部门、直属上级、员工类型、入职日期等），两个后台的信息是自动同步更新的。
- **Q：转正、离职等审批可以由他人代发起吗？**
  A：可以。转正、离职等审批可由待转正员工本人发起或由其他人代发起。
- **Q：员工入转调离审批通过后，花名册中的员工状态会自动同步吗？**
  A：会的。如在审批单中使用了飞书人事（标准版）提供的审批套件，转正、调动审批通过后，员工状态会在转正日期、调动日期到期后自动生效。离职审批通过后，也会自动进入待离职列表。
- **Q：员工在飞书人事（标准版）办理入职后，还需要在飞书后台给该员工开通账号吗？**
  A：不需要，在飞书人事（标准版）中点击 确认入职 按钮后，会自动为该员工开通飞书账号。
- **Q：飞书人事（标准版）后台的职位是需要一个个添加吗？**
  A：不需要。管理员可以通过花名册的 批量更新 功能，将员工 职位 信息批量导入，飞书人事（标准版）会自动创建职位。

### 出自《飞书招聘常见使用问题》
原文：https://www.feishu.cn/hc/zh-CN/articles/355896296441-飞书招聘常见使用问题

- **Q：是否有动态的招聘需求管理统计看板？**
  A：点击 职位 > 招聘需求，即可看到需求管理的统计看板，可查看需求人数、待入职、已入职，还可以根据具体需要进行筛选。 二、招聘执行 职位 / 渠道广告管理
- **Q：飞书招聘系统内，是否允许同一候选人在同一职位上重复投递？**
  A：同一候选人在同一职位上只能有 1 个正在流程中的投递。因此，若该候选人在该职位上已有处于流程中的投递（活跃投递），则不允许重复创建；若候选人在该职位上的投递是已终止的投递，则允许创建新的投递。
- **Q：如何刷新发布在第三方渠道的职位广告？可一键刷新或自动刷新吗？**
  A：勾选需要刷新的职位，然后点击职位列表页面右上角的 刷新职位广告 按钮，即可选择需要刷新的渠道，进行单个渠道刷新。目前支持批量上/下线职位广告到内推、官网、猎头平台等渠道。 注意：刷新职位广告会将已上线广告 靠前展示 或 置顶，并不会自动同步更新后的职位信息到职位广告，若需修改职位广告内容，需要单独进入第三方渠道对职位广告内容进行编辑。
- **Q：职位上线后，更新了职位信息，怎么同步到渠道广告？**
  A：更新的职位信息不会自动同步到渠道广告，可以通过以下两种方式进行操作： 先把这个职位在第三方渠道下线，然后在飞书招聘重新上线发布。 在第三方渠道上手动更新职位信息。
- **Q：在系统下线职位广告后，是否需要去第三方渠道再下线一次？**
  A：不用。可按照如下操作在系统中直接下线第三方渠道的职位广告。 点击 下线 按钮，跳转至招聘渠道页面，自动下线 职位详情页顶端，将通知显示下线成功 注意：职位广告下线后，如重新上线，会在第三方渠道再新建一个职位广告，而不是更新原有的。
- **Q：目前已支持投递的第三方渠道有哪些？**
  A：目前已支持的有 10 家：拉勾、猎聘、前程无忧、智联、脉脉、领英、实习僧、应届生求职网、赶集网、58同城、中国汽车人才网。
- **Q：职位列表加载不出来，显示白屏？**
  A：建议可以清除一下所使用浏览器的缓存，之后再刷新页面看是否恢复正常。 以 Google Chrome 为例（360 浏览器类似）： 1.点击浏览器右上方 ... 按钮，选择 更多工具 > 清除浏览数据。 2.然后在弹窗选择 清除数据。
- **Q：飞书招聘对三方招聘渠道虚拟号如何让进行处理？**
  A：智联、猎聘、51 job 的候选人简历联系方式采用了虚拟号码代替候选人真实号码。招聘网站的改版影响了所有招聘系统的候选人信息获取操作。飞书招聘进行了修复和调整，针对智联、猎聘、51 job 的的情况做出了如下应对措施： 51 job 、猎聘候选人主动投递的简历信息收取不受影响，已通过技术方式解决候选人联系方式的主动获取问题; 智联招聘中，候选人主动投递的简历，由于号码隐藏导致入库的候选人没有联系方式。建议通过配置“待分配简历池”规则，由系统将候选人归置到相关职位上， HR 需要到招聘网站上手动操作（比如点击“立即聊”），才能获取真实手机号， 接着在飞书招聘系统上，搜索到对应候选人，添加候选人的联系方式。 在招聘网站上主动搜索的简历，依然可以通过飞书招聘的插件进行一键入库，由于虚拟号码产生的问题，如果后台配置手机号码必填，则会进入待分配简历池，建议通过配置“待分配简历池”规则，由系统将候选人归置到相关职位上。 通过招聘网站提供的虚拟号码进行拨打，同候选人确认基本情况，并获取候选人联系方式，回到飞书招聘系统，搜索到对应候选人，修改为真实正确的联系方式。 另外，若可接受库内简历重复，可让招聘管理员通过设置 > 招聘过程管理 > 候选人信息管理 > 候选人字段管理，将候选人信息中的电话、邮箱配置为非必填字段，这样候选人依然可自动入库且归类职位。
- **Q：对于“同一个职位，多个工作地，企业希望多个工作地投递的候选人都在飞书招聘的同一个职位下”，该如何实现？**
  A：如果招聘渠道支持发布职位时的职位工作地可以多选，如猎聘，就可以在飞书招聘上创建一个职位，职位工作地点选择多个工作地中的任意一个或者选不限，之后通过招聘插件到渠道上发布职位，渠道上工作地址可以填写多个。发布后，在渠道上会出现多个岗位（岗位名称和描述一样，工作地不一样），后续候选人投递了归属这几个岗位的简历，都会统一合并到飞书招聘的同一个职位下。 本质上：邮箱拉取简历与系统里的职位进行匹配，根本逻辑是看邮箱里职位名称编码是否和系统里的职位名称编码一致。 如果招聘渠道不支持职位工作地“多选”，在飞书招聘上创建完该岗位后，可以在 职位详情页 > 招聘渠道 > 新建职位广告 > 编辑职位广告修改地点 > 上线第三方渠道 即可。通过这种方式也能实现渠道上的多个岗位（岗位名称和描述一样，工作地不一样）的投递简历合并到飞书招聘的同一个职位下。
- **Q：相似人才推荐功能已上线，哪些人可以看到某个职位下简历的相似人才推荐?**
  A：只有该职位的创建人和招聘负责人，可以看到该职位下的且在职位流程中（简历筛选 > 已终止）的人才的相似人才推荐。飞书招聘的招聘管理员如果不是该职位的创建人或招聘负责人，也无法看到相似人才推荐。
- **Q：新建职位时，职位亮点能否自定义？**
  A：系统预置了 16 个亮点标签：下午茶、瑜伽健身、六险一金、五险一金、股票期权、团队氛围好、晋升空间大、带薪休假、扁平管理、用户过亿、大牛带队、餐补、免费三餐、薪资优厚、弹性工作、租房补贴。发布职位时可以选择。暂未支持用户直接自定义的标签。
- **Q：职位创建时的“招聘负责人”、“用人经理”、“招聘协助人”有什么区别？**
  A：招聘负责人：可以查看并操作（安排评估、面试等）该职位下的全部候选人。只能设置一人。 用人经理：只能查看该职位下的全部候选人，但没有操作权限。可以设置多人。 招聘协助人：和招聘负责人的权限一致，但在普通员工的内推职位页面、报表分析中，HR 一栏都只会显示招聘负责人，而不会显示协助人。可以设置多人。 候选人管理
- **Q：第三方渠道投递的简历为什么没有进入候选人列表？**
  A：可能是进入了待分配简历池。 在飞书招聘首页，点击左侧筛选任务中的待分配简历，进入待分配简历池。 进入后默认展示有职位的简历，该页面下的候选人为：飞书招聘获得了候选人在第三方渠道的职位信息，但是与飞书招聘系统内的职位匹配失败，需要手动分配职位。对于有职位的简历，你可以在手动分配职位时，设置该职位的简历分配规则，后续该职位简历都将按照规则自动分配。 点击无职位页面，该页面中的候选人为：飞书招聘未能获得候选人在第三方渠道的职位信息，但是获得了完整的候选人信息，需要手动分配职位或加入人才库。 点击进入待完善简历页面，检查通过第三方渠道投递的简历是否缺少候选人必填信息，完善信息后即可加入到人才库中。 如果在待分配简历池中仍未找到候选人简历，请联系所在公司的飞书招聘管理员，依次检查如下事项： 拉勾网是否已配置好账号和密码，其他渠道是否已配置好简历接收邮箱。如同一渠道有不同账号和邮箱，需把所有账号和邮箱信息配置好。 配置在飞书招聘中的简历接收邮箱与第三方渠道上接收简历的邮箱是否一致？若不一致，请联系管理员在飞书招聘中更新邮箱信息。 近期是否修改过简历接收邮箱密码，如进行过修改，请尝试在飞书招聘中更新邮箱密码。
- **Q：为什么从第三方渠道上收到的简历，导入飞书招聘系统后通过姓名搜索不到？**
  A：首先请确认是否在设置中成功配置了第三方招聘渠道的简历接收邮箱。 如已配置，但仍搜索不到简历，可能是系统没有成功解析出该候选人简历上的姓名信息，可尝试通过其他的方式进行搜索，例如：在对应职位中进行查找。
- **Q：人才锁显示红色和绿色分别代表什么意思？**
  A：绿色：目前候选人被锁定的职位，是用户作为职位负责人 / 协助人的职位。 红色：目前候选人被锁定的职位，不是用户作为职位负责人 / 协助人的职位。因此即使候选人投递了该用户有权限的岗位，如果 Ta 在其他岗位上已被锁定，那么也显示红色。
- **Q：如何转移候选人的投递职位（转岗）？**
  A：如下图示意，点击 转移职位 按钮，即可转移候选人的投递职位。转移后当前投递将自动终止。
- **Q：为什么候选人详情页标准简历中的来源会有多个？**
  A：这里显示的来源是这份简历所有来源的汇总。比如，有一位 HR 从第三方渠道获取该候选人简历后将其加入了 A 职位，之后又有一位 HR 从社交媒体上获取了同一候选人的简历，将简历手动上传更新后加入了 B 职位，那么这两个来源都会显示在这位候选人详情页下的标准简历中。 注意：每次投递到职位的简历来源可在候选人详情页右侧查看（见下图）。
- **Q：候选人多次投递简历的话，系统是否会自动更新简历？**

  A：笔试结论：不从生态伙伴取数，由面试官 / HR在飞书招聘阅卷获得。 笔试分数：可以由生态供应商传输，也可以由阅卷人阅卷获得。 如果由生态供应商传输，逻辑是：供应商回传有“总分”这个字段和数据，就会自动写到飞书招聘的“笔试分数”里，这里细分两类。 第一类是牛客、赛码：回传数据里有“总分”，总分会直接作为飞书招聘的“笔试分数”。 第二类是北森、SHL：北森的标准版设计上就没有“总分”字段（只有状态和详细成绩），也就是说虽然飞书招聘会始终会去抓“总分”，但北森标准版里没有该字段，抓不到。（如果是非标准版测评，北森可以 by 客户定制非标准版，需要客户跟北森沟通，有些竞品招聘系统也会给客户做定制，不过飞书招聘不支持定制）。SHL 跟北森同理。 面试

- **Q：在内推平台上，社招职位的操作里有“内推”和“分享”两种方式，为什么在校招职位的操作里只有“分享”一种方式？**

- **Q：面试速记是否能被其他人看到？**
  A：如果点击开启 面试速记 后，面试速记记录的语音转文字内容将会被该候选人的其他面试官或者 HR 看到速记内容，方便他们进行接下来的考察判断。如果你觉得该场「面试速记」内容非常隐私，你可以选择在面试完成后对面试速记进行删除。点击在面试速记详情右上角的删除按钮即可删除。
- **Q：面试中进行自动语音转文字是合规的吗？**
  A：是合规的。过程中不会录制语音或者收集声纹信息，只将面试对话实时转为文字记录。面试官可以在面试中随时暂停或者删除整场面试记录；如果不需要该功能，面试官可以在飞书招聘的设置页面关闭面试助手。

- **Q：面试题库的题目来源是哪里？**
  A：面试题库来源于字节跳动内部各个序列的面试官最常问的高频问题，经过清洗标注、专家审核后整理出来的，包含互联网行业常见职位类别的专业题目以及旨在考察候选人背景和软素质的通用题目。 面试题库中的考点是专家拟定、以及从海量简历和职位信息中清洗和整理的，暂不支持用户自定义考点。

- **Q：目前支持哪些操作系统？哪个操作系统版本更适合我？**
  A：目前仅支持 Windows 和 macOS 系统。Windows 系统的在兼容性上更优，macOS 系统在稳定性上更好。各操作系统的最低版本要求及推荐如下： Windows 需要 64 位或以上操作系统版本，推荐 Windows Server 2012 R2 或以上； macOS 需要 10.15 或以上操作系统版本。 注：由于厂商驱动程序兼容性问题，如果你使用的是佳能 Canon、震旦 Aurora、东芝 Toshiba 的打印机，建议使用 Windows 操作系统作为云打印的服务器。
- **Q：云打印服务器能否使用 Linux 系统？**
  A：目前仅支持 Windows 和 macOS 系统，其他如 Linux、Unix 操作系统暂不支持。
- **Q：服务器有没有什么硬件上的要求？**
  A：硬件没有具体要求，可参考对应操作系统的推荐配置。
- **Q：云打印服务器能否使用虚拟机？**
  A：云打印服务器可以运行在虚拟机中，使用虚拟机时请分配足够的资源，以保障操作系统运行流畅。具体的配置要求，请参考对应操作系统的推荐配置。
- **Q：可以直接从云打印采买硬件，用来部署服务器吗？**
  A：暂时不支持购买。可以考虑使用普通办公电脑作为云打印服务器。
- **Q：macOS 和 Windows 服务器能并行吗？备用机怎么配置？**
  A：企业可以同时部署 macOS 和 Windows 服务器。当同一台打印机同时连接了 macOS 和 Windows 云打印服务器时，每次打印将随机选择一台可用的服务器。
- **Q：为什么 Windows 版本的服务器，在客户端安装后无法打开？**
  A：目前 Windows 版本的服务器仅支持 Windows 7 及 64 位以上的 Windows 版本。若安装失败或无法使用，请确认电脑系统是否符合标准。
- **Q：为什么服务器处于离线状态？**
  A：- 请确认是否是网络问题或服务器客户端不在运行状态，请尽量保证安装服务器的电脑为运行状态，关闭电脑自动休眠，且网络畅通；对于 macOS 电脑，请开启自动登录。 - 请更新系统根证书
- **Q：在安装服务器客户端的电脑上打印出错，导致打印机无法使用怎么办？**
  A：部分 Windows 或 macOS 系统更新，可能会导致服务器偶发报错。此时请尝试在电脑中删除当前的打印任务，并重启电脑。

## 云文档
### 出自《云文档本地记录常见问题》
原文：https://www.feishu.cn/hc/zh-CN/articles/360046996234-云文档本地记录常见问题

- **Q：什么是云文档？**
  A：云文档是飞书的办公套件，包括文档、表格、多维表格、知识库、模板库等工具。
- **Q：什么是本地记录？**
  A：本地记录是云文档的一项记录保存功能。网络中断时，你对云文档的编辑操作会被自动保存为本地记录。当网络恢复时，本地记录会自动同步到云端。
- **Q：本地记录和历史记录的区别？**
  A：本地记录可以在网络中断时，实时保存你自己对云文档的离线编辑。当网络恢复时，这些操作记录会自动同步到云端，并展示在历史记录中。而历史记录可以在网络通畅时，实时保存所有云文档协作者对云文档的线上编辑。
- **Q：什么情况下本地记录会消失？**
  A：通常情况下，当联网同步数据后，不再保留已经同步到云端的本地记录。你可以在历史记录中查看对应的修改细节。此外，本地记录保存在你的本地浏览器中。如果你清除了浏览器 Cookies 及缓存数据，则本地记录也相应被清除。
- **Q：如何查看云文档的本地记录？**
  A：你无法查看自动保存的本地记录。网络中断时自动保存的本地记录，在下次联网后自动同步到云端；网络正常状态下不会自动保存本地记录。 - 如需查看历史版本的内容，你可以点击 ••• 图标 > 历史记录，按编辑时间寻找历史内容。 - 文档、表格支持在移动端设置为离线可使用，具体信息请参考[在移动端离线编辑文档](https://www.feishu.cn/hc/zh-CN/articles/369694430610)。
- **Q：什么情况下会保留本地记录？**
  A：当你的网络中断时，云文档的其他协作者可能修改了此云文档，这样一来，可能存在你们以不同的方式，修改了同样内容的情况，使编辑操作产生冲突。联网后，系统将根据你们编辑时间的先后等因素，综合多方的修改细节来同步线上云文档。 为避免联网后因编辑冲突导致离线操作细节丢失，当你的离线操作和线上用户的在线操作产生冲突时，飞书云文档将保留你的本地记录，方便你随时查看此次离线编辑的所有操作，进而根据实际情况判断是否需要手动恢复操作记录。
- **Q：他人是否能看到我的本地记录？**
  A：不能。本地记录保存在你的本地浏览器中，只有你可以看到。

### 出自《云文档权限常见问题》

- **Q：为什么我自己的云文档，却无法编辑？**
  A：如果出现此类情况，可从以下两方面检查问题。 如果你有多个飞书账号，请检查浏览器所登录的账号与该云文档所在账号是否一致。 如果是上传的 Word、Excel 文件，请点击界面右上方的 编辑文件 > 用WPS在线编辑，开启编辑模式。 注：如果上传的文件右上角不显示 编辑文件 按钮，请确认文件类型。CSV 表格、PDF、视频、图片文件不支持直接在线编辑。 尝试在浏览器无痕模式下编辑，如果可以正常编辑，则可能是浏览器缓存或扩展程序冲突问题。可以尝试清理浏览器缓存，调整扩展程序权限，或移除/关闭扩展程序，之后再尝试编辑。有关解决扩展程序与文档冲突的具体信息，请参考解决 Chrome 扩展程序与文档的冲突。
- **Q：为什么我不能评论云文档？**
  A：可能是云文档权限设置中“谁可以评论”一项选择了可编辑的用户，你可联系所有者修改该设置或者申请编辑权限。
- **Q：为什么我无法分享某个云文档？**
  A：请确认你是无法分享给组织内外任何用户，还是仅能分享给组织内部用户，但无法分享给组织外部用户。 无法分享给任何用户： 可能是因为你没有添加协作者的权限。你可以在邀请协作者时，向云文档所有者发起申请；或者联系所有者修改权限设置。有关修改权限设置的具体信息，请参考设置云文档分享、复制、下载、评论等权限。 可以分享给内部用户，但无法分享给外部用户，可能的原因有： 云文档所有者、可管理的协作者禁止对外分享此云文档，请联系所有者修改设置。 云文档所在的知识库安全设置禁止对外分享，请联系知识库管理员修改设置。 企业管理员禁止将组织内云文档分享至组织外部，请尝试联系管理员修改设置。
- **Q：如何将应用添加为云文档协作者？**
  A：云文档的所有者、其他有可管理权限的协作者，可以按以下步骤将应用添加为文档、表格、多维表格、幻灯片等云文档的协作者。 打开云文档，点击 图标 > ••• 更多 > 添加文档应用， 搜索并选择目标应用，为应用分配 可管理、可编辑 或 可阅读 权限。 点击 添加。该应用将出现在当前云文档的协作者列表，你也可以修改其权限。 有关为应用开通权限的具体信息，请参考如何为应用开通云文档相关资源的权限。
- **Q：他人分享给我的云文档，我可以主动放弃阅读权限吗？**
  A：如果你有管理该云文档协作者的权限，你可以通过移除自己的云文档协作者身份，放弃云文档的阅读权限。暂不支持批量操作多个云文档。 1. 打开云文档，点击右上方的 分享 按钮，点击所有者头像，进入 管理协作者 页面。 2. 点击你的当前权限，在下拉菜单中，点击 移除。你会看到移除成功的提示。 移除协作者身份后，只要你不在云文档的链接分享范围内，你将无法访问这个云文档。 如果你点击所有者头像无法打开 管理协作者 页面，则你没有管理协作者权限，请联系云文档所有者移除你的协作者身份。
- **Q：我的云文档有外部用户访问，如何关闭外部分享？**
  A：点击云文档右上角 分享 > 权限设置，在 对外分享 设置项下，取消勾选 允许内容被分享到组织外，即可关闭该云文档的外部分享。之前获得阅读权限的所有外部用户不再有权限访问。
- **Q：如何让协作者只能编辑云文档的部分内容？**
  A：根据云文档内容类型不同，支持的操作不同。 文档、幻灯片、思维笔记：不支持限制编辑范围，有可编辑权限的协作者能编辑整个文档、幻灯片、思维笔记。 表格：你可以使用保护表格数据功能，限定谁可以编辑被保护区域。 多维表格：你可以使用高级权限功能，设置指定人员编辑指定行、列的权限。
- **Q：如何撤回、修改授予给他人的权限？**
  A：如果你有管理该云文档协作者的权限，你可以撤回、修改其他人的协作者权限。暂不支持批量操作多个云文档。 1. 打开云文档，点击右上方的 分享 按钮，点击所有者头像，即可进入 管理协作者 列表。 2. 找到你想对其撤回、取消权限的协作者，点击其右边对应权限，修改为其他权限或者点击 移除。 如果你点击所有者头像无法打开 管理协作者 页面，则你没有管理协作者的权限，请联系云文档所有者为你开通权限或者替你操作。
- **Q：如何批量调整云文档权限？**
  A：对于自己为所有者的云文档，你可以使用云文档的权限管理工具，进行批量权限调整，具体信息请参考筛查并管理云文档权限。 对于所有者为他人的文档，不支持批量调整。你可以将需要调整权限的所有云文档移动到同一个文件夹中，通过调整文件夹的权限，如添加协作者、修改链接分享范围，实现批量调整文件夹中云文档的权限，具体信息请参考分享文件夹。
- **Q：如何找到离职员工的文档和文件夹？**
  A：通常情况下，企业管理员会将离职员工的文档和文件夹所有权转移给其直属上级。员工离职后，其直属上级会收到一个名为 [员工姓名]的个人文档 的文件夹，文件夹内包含该离职员工的全部云文档和文件夹。
- **Q：为什么在浏览器和飞书客户端，云文档主页显示的内容不同？**
  A：同时在浏览器和客户端访问云文档主页，如果你发现主页列表中显示的内容不同，或者有云文档在浏览器可访问，在客户端找不到，请确认浏览器和客户端登录的是否是同一个飞书账号。有关切换账号的具体信息，请参考切换云文档的登录账号、切换账号。

  A：绿标是出现在表格单元格左上角的绿色小三角。如果某单元格左上角出现绿标，则表示该单元格内的数字以文本格式存储，即为文本型数字。这种文本格式的数字仍然为文本格式，失去了作为常规数字的属性，不能用于公式计算；出现绿标的单元格文本自动向左对齐。 例如， 在纯文本格式单元格中输入数字，然后将数据格式调整为数字，单元格左上角就会出现绿标。
- **Q：在表格中如何将绿标单元格转换为非绿标单元格？**
  A：选中绿标单元格，点击 信息 图标，然后点击 转为数字 即可完成转换。 如果你想要批量转换，你可以选中绿标单元格区域，点击 信息 图标，然后点击 转为数字 即可。注：批量转换时，所选中的单元格区域中可包含无绿标单元格，但首个选中的单元格必须为绿标单元格，否则不会显示信息图标。
- **Q：表格中的长数字转换为非绿标单元格后，为什么数据存在偏差或无法展示完整数字？**
  A：如果在单元格中输入超过 15 位的数字，该单元格将会出现绿标，此时转为数字格式后，表格会使用科学记数来展示该数字。例如，把含有数字 123456789123456789（共 18 位数字）的绿标单元格转为数字格式后，该数字将显示为 1.23457E+17。 所以，若你想要输入身份证信息并完整展示，为了避免绿标转换导致的问题，建议提前将单元格的数据格式设置为纯文本类型。

### 出自《多维表格函数常见问题》
原文：https://www.feishu.cn/hc/zh-CN/articles/665637142562-多维表格函数常见问题

- **Q：如何修改多维表格公式字段的显示？**
  A：双击公式字段的名称，点击 字段格式，选择所需的显示方式即可。目前多维表格公式字段支持整数、小数、千分位、百分比、货币、日期等格式。
- **Q：为什么多维表格 TEXT() 函数计算出来的结果为数字时，在其他函数中计算会出错？**
  A：TEXT() 函数计算出来的结果属于文本格式，你可以通过 SUM() 或者 ABS() 函数将计算结果变成数据后，进行引用或计算。
- **Q：为什么多维表格显示公式无效？**
  A：可能有以下几种原因： 公式中用到的运算符号和括号等不是英文符号，例如：“文本” 应该为"文本"。 括号数量不匹配，例如：IF(TRUE, 0, 1)) 应该为 IF(TRUE, 0, 1) 。 公式中存在无效数据，例如：SUM([字段A]) 中，字段A 被删除或不存在。 百分数格式不正确，参与计算时，百分数应写成小数形式，例如：0.01。 使用的运算符号不正确。 数据的格式不正确，如果涉及同步操作，需要在同步前调整好数据格式。
- **Q：多维表格公式中常用的运算符号有哪些？**
  A：*符号类型 运算符 说明 逻辑运算符 && 并且 *|| 或者 > *大于 >= *大于等于 < *小于 <= *小于等于 = *等于 != *不等于 文本链接符 & 将两个文本进行拼接 数值运算符 + *两个数值相加 - *两个数值相减 * *两个数值相乘 / *两个数值相除 % *取余
- **Q：为什么多维表格求和的结果不正确？**
  A：仅支持对公式字段和数字字段中的数据进行计算，请确认进行计算的字段类型不是文本字段； 数据精确度较高时，请将数字位数调整为小数点后 4 位，再确认计算结果。
- **Q：多维表格公式中百分数如何表示？**
  A：在多维表格公式中，百分数需写成小数形式才能参与计算。例如：10% 在公式中应为 0.1。
- **Q：多维表格公式字段中日期函数的运算结果的数据格式是什么？**
  A：公式字段中日期函数的运算结果是以时间戳形式存储的。尽管多维表格支持在字段的格式设置中指定日期格式，但该设置仅将结果显示为日期，并未转换数据格式。数据仍以时间戳格式存储。 因此，系统仍会将此类数据识别为时间戳。例如在对该字段进行筛选时，筛选条件与数字的筛选条件相同，而非日期。
- **Q：在多维表格中使用 & 符号进行文本拼接时，日期的结果为什么显示的是数字？**
  A：直接使用 & 符号进行文本拼接时，日期的结果会被识别为数字，所以在对日期进行文本拼接时，需要使用 TEXT() 函数将日期转换为文本格式。
- **Q：多维表格公式计算出来应该是日期，为什么显示的是数字？**
  A：数字是日期格式的运算值，若公式运算的最终结果格式显示不准确，可双击字段名称，将字段调整为日期格式。对于货币、百分比等格式也可采取相同操作。 注：在公式字段中使用日期相关的函数时，运算结果实际是以时间戳格式存储，而非日期。即使选择了以日期格式显示，系统仍会将该字段识别为时间戳。
- **Q：多维表格公式中如何表示为空？**
  A：可以用 = ""，也可以用 ISBLANK() 函数。例如：IF([日期]="","为空","不为空")或 IF([日期].ISBLANK(),="","为空","不为空")。
- **Q：多维表格公式中被引用的日期应该如何书写和参与计算？**
  A：有以下两种情况； 当公式中引用的数据本身就是日期字段类型时，可以直接参与计算。例如：下图结束时间和开始时间均为日期字段，直接相减即可得出相差的天数。 当日期为一个固定的文本时，可以通过 TODATE() 函数将输入的文本转换为日期。例如：下图 2022/05/01 是一个固定的日期，需要用 TODATE() 函数进行转换后才能参与计算。 注：文本需用英文双引号括起来，公式才能生效。
- **Q：多维表格 TEXT() 函数支持哪些自定义格式？**
  A：常见格式请见下表； *格式与占位符 说明 举例 # 数字占位符，用于自定义数字格式 TEXT(23.1,"##.#")=23.1 TEXT(23.17,"##.#")=23.2 0 数字补位符，用于自定义数字格式 TEXT(23.1,"0.00")=23.10 TEXT(23.17,"0.00")=23.17 , 千位分隔符，在 # 或者 0 之间使用 TEXT(23100,"0,0")=23,100 % 百分号，需与 # 或者 0 结合使用 TEXT(23,"0%")=2300% YYYY 年份全称 TEXT("2022-4-15","YYYY")=2022 TEXT("2022-4-15","YYYY年")=2022年 YY 年份缩写 TEXT("2022-4-15","YY")=22 TEXT("2022-4-15","YY年")=22年 MMM 月份全称 TEXT("2022-4-15","MMM")=4月 MM 月份数字全写 TEXT("2022-4-15","YYYY/MM")=2022/04 TEXT("2022-4-15","MM月")=04月 M 月份数字简写 TEXT("2022-4-15","M")=4 TEXT("2022-4-15","M月")=4月 DD 日全写 TEXT("2022-4-1","DD")=01 TEXT("2022-4-1","DD日")=01日 D 日简写 TEXT("2022-4-1","D")=1 TEXT("2022-4-1","D日")=1日 DDDD 星期全称 TEXT("2022-4-1","DDDD")=星期五 DDD 星期简称 TEXT("2022-4-1","DDD")=周五 hh 小时 TEXT("17:30","hh")=17 mm 分钟 TEXT("17:30","hh:mm")=17:30 ss 秒钟 TEXT("17:30:29","ss")=29
- **Q：为什么使用多维表格 IFS() 函数时公式书写没有任何错误，结果却显示 #N/A？**
  A：当数据不满足 IFS() 中任意一个条件时其结果将为 #N/A，为避免这种情况，可以在公式最后添加一个特殊条件。例如：IFS([成绩]=100,"满分", [成绩] >=85,"优秀", [成绩] >=75,"良好", [成绩] >=60,"及格", TRUE,"不及格" ) ，上述公式中的 TRUE,"不及格" 即为一个特殊条件，即所有不满足前三个条件的数据结果都将显示为“不及格”。
- **Q：在多维表格中，已知一个日期，怎样计算在该日期特定工作天数后的日期？**
  A：可以使用 WORKDAY(起始日期, 天数, [节假日]) 函数计算在一个日期的特定数量工作日之后的日期。如，要计算 2024/11/01 之后 10 个工作日的日期，可使用 WORKDAY("2024/11/01", 10)。 该函数默认将周六和周日视为非工作日。如需包含其他节假日，可通过 [节假日] 参数进行定义。该参数需为一个包含日期的数组。可预先定义一个日期字段，并将其设置为 [节假日] 参数。
- **Q：如何使用多维表格公式快速统计字段中值的个数？**
  A：可以使用 COUNTA(值1, [值2, ...]) 函数统计数据集中非空值的个数。 如，使用该函数统计人员字段中人员的个数：COUNTA([人员字段])；或附件字段中附件的个数：COUNTA([附件字段])。如果输入多个参数，COUNTA() 会统计参数值的总个数，应确保统计结果是有意义的。
- **Q：在多维表格中，如何使用公式将文本转为日期？**
  A：可以通过 TODATE 函数将输入的文本转换为日期。如：在统计某一时间段内的销售额时，需要在公式中将文本转换为时间。 例：[数据表].FILTER(CurrentValue.[时间] > TODATE("2021/12/31")  && CurrentValue.[时间] < TODATE("2022/12/31"))
- **Q：多维表格的单个公式字段中可引用字段的数量上限是多少？**
  A：单个公式字段中最多可以引用 300 个字段。
- **Q：多维表格如何跨数据表查询重复字段？**
  A：如果要跨数据表查找重复字段并进行标注，可以使用公式字段。将公式设置如下，并将公式中对应的数据表和字段名修改为你需要查重的数据表和字段：IF([数据表 2].COUNTIF(CURRENTVAlUE.[数据表 2 查重字段]=[当前表查重字段]) = 0, "不重复", "重复")。 该公式字段将使用“重复”和“不重复”标注查重结果。
- **Q：如何在多维表格数据表中按行对数据进行基础运算？**
  A：如果仅需要按行进行运算，只需新增一个公式字段，在公式中引用相应的字段并添加运算符即可，如“[字段 1] + [字段 2] * [字段 3]”。

  A：可能有以下原因： 当你仅拥有多维表格的阅读权限时，将无法看到工作流或自动化入口。 针对已分享到组织外的多维表格：如果多维表格的权限设置中（路径：点击多维表格右上角的 分享 > 权限设置）勾选了“仅组织内的用户可以查看、添加、移除协作者”，那么外部用户（与多维表格所有者不在同一个企业组织内）即使拥有可管理权限，也无法看到工作流或自动化的入口。
- **Q：谁可以创建、编辑和删除工作流或自动化流程？**
  A：未开启高级权限时，多维表格所有者、拥有可管理和可编辑权限的用户可以创建、编辑和删除工作流或自动化流程；若用户失去了可编辑/可管理权限，由该用户启用的工作流或自动化流程可能会自动转交给新的所有者或停止运行。如果工作流或自动化流程停止运行，有多维表格编辑权限的用户可以再次启用此流程。 开启高级权限后，仅多维表格所有者和拥有可管理权限的用户可以创建、编辑和删除工作流或自动化流程。若用户失去了可管理权限，由该用户启用的工作流或自动化流程可能会自动转交给新的所有者或停止运行。如果自动化流程停止运行，多维表格所有者或其他拥有权限的用户可以再次启用此流程。 关于工作流或自动化流程转交逻辑的具体信息，请参考多维表格工作流和自动化流程转交说明。 注：有权限的外部用户（与多维表格所有者不在同一个企业组织内）可以创建流程、删除未 被启用的流程，但不能启用或停用流程。外部用户对流程做的编辑可以被保存但不能被启用。
- **Q：每个多维表格支持创建多少个工作流或自动化流程？**
  A：每个多维表格中，工作流或自动化流程的创建上限各为 200 个。 注：以“到达记录中的时间”为触发条件的工作流或自动化流程，创建上限各为 100 个。

- **Q：如何计算工作流和自动化流程的运行次数？**
  A：任一工作流或自动化流程，无论包含多少节点，只要被触发且运行成功，均计为一次运行。例如，当任务信息有更新时，成功给任务负责人发送消息提醒，此流程中包含两个节点，计为一次运行。
- **Q：如何在工作流或自动化流程中引用公式计算出来的日期？**
  A：当你在工作流或自动化流程中引用公式计算出来的日期，用于填充日程或任务的起止时间、或其他日期字段时，务必保证公式正确，且在 字段格式 处选择了“日期”格式。“默认”格式或其他格式的计算结果都无法被识别成日期。同理，在使用工作流或自动化流程更新数字等其他字段类型时也是如此，需为计算结果选择合适的格式，以确保内容填充正确。
- **Q：使用工作流或自动化流程发送消息时，消息中的数字不按照设定好的格式显示，怎么办？**
  A：当你使用工作流或自动化发送消息，并引用了数字格式的内容时（可能是数字字段，或是计算后的公式或查找引用字段），保留几位小数、百分比等格式设置都不会被保留，需要使用公式来改写格式。例如，如果你想实现“保留两位小数”的效果，可使用 Text 公式，比如 TEXT([原字段]，"0.00")，然后把字段格式改为默认或者文本。如果想展示百分比，就需要用 ROUND 函数取 2 位小数、*100，再拼接 % 符号。
- **Q：为什么使用工作流或自动化流程发送的消息不展示多维表格内的内容？**
  A：这可能是由于你点击的是 发送预览 按钮，并非真正触发了工作流或自动化流程。点击 发送预览，预览的消息会发送给当前的流程配置者，引用的字段会以“[字段标题]”的形式展示，仅供预览效果。预览消息中无法展示多维表格中实际的字段内容。
- **Q：我可以在工作流或自动化消息中添加链接吗？**
  A：可以。你可以在“发送飞书消息”中打开 添加底部按钮，即可自定义按钮的标题和跳转的链接。
- **Q：在工作流或自动化的触发条件中，是否可以选择公式和查找引用字段？**
  A：可以，当触发条件为“修改记录时”，公式字段和查找引用字段可以作为关注的字段。需注意，仍存在部分无法使用的情况： 多维表格创建的时间较早，导致无法使用。请尝试新建多维表格后使用。 单个数据表内的公式和查找引用字段总数超出 100 个时，将无法使用。 多维表格内存在计算慢的公式，可尝试对公式进行优化后使用。详情可查看多维表格公式计算优化指南。
- **Q：多维表格工作流或自动化流程是否支持以“删除”作为触发条件或执行操作？**
  A：不支持。多维表格的工作流或自动化流程不支持以“删除”作为触发条件，也不支持删除操作。
- **Q：多维表格工作流或自动化流程是否可以一次新增多条记录？**
  A：工作流或自动化流程不支持一次新增多条记录。但你可以在工作流中使用循环节点批量新增记录，具体信息请参考工作流循环功能场景实践。
- **Q：怎样查看我的企业里工作流或自动化流程运行了多少次？**
  A：企业超级管理员或拥有多维表格流程用量权限的管理员，可以在管理后台的企业管理 > 费用中心 > 权益数据 页面，查看多维表格自动化流程的用量和额度。
- **Q：可以使用多维表格工作流或自动化流程删除指定记录吗？**
  A：多维表格工作流或自动化流程不支持删除记录操作。

### 出自《多维表格高级权限常见问题》
原文：https://www.feishu.cn/hc/zh-CN/articles/892315791286-多维表格高级权限常见问题

- **Q：收费版本过期后，会影响到我设置的高级权限吗？**
  A：已设置的高级权限将不会受到影响，但收费版本过期后，修改或新增高级权限可能会被限制。
- **Q：为什么我的多维表格没有高级权限的入口？**
  A：可能是以下 2 种情况： 在电子表格或文档中插入的多维表格，不支持高级权限功能。 在多维表格中，仅多维表格所有者或拥有多维表格的可管理权限的协作者能看到高级权限的入口。
- **Q：谁可以启用、修改、关闭高级权限？**
  A：多维表格所有者或拥有多维表格的可管理权限的协作者可以启用、修改、关闭高级权限。
- **Q：设置各行记录的高级权限时，哪些字段可视为筛选条件？**
  A：支持将以下类型的字段设置为筛选条件： 单选、多选字段 人员、创建人字段 流程字段 包含数字、进度条、评分、货币在内的数字类字段 输出结果为前述字段类型的公式字段和查找引用字段 支持设置多个筛选条件，最多可设置 10 个筛选条件。公式字段需与被引用字段的样式保持一致。 注：若出现以下情况则无法使用公式字段和查找引用字段作为筛选条件： 多维表格创建的时间较早。 单个数据表内的公式和查找引用字段总数超出 100 个。 多维表格内存在计算慢的公式，可尝试对公式进行优化后使用，具体信息请参考多维表格公式计算优化指南。
- **Q：当一个用户同时出现在高级权限的多个权限角色中，最终的权限会是什么？**
  A：开启高级权限后，拥有多个权限角色的单个用户，会拥有被赋予的所有权限的并集。例如： *用户拥有的权限角色 用户的实际权限 *在权限角色 A 中，拥有可编辑数据表前三行记录，不可查看其余记录 *在权限角色 B 中仅可查看数据表全部记录 *该用户可编辑数据表前三行，并查看全部记录。 *在权限角色 A 中可编辑全部字段和记录 *在权限角色 B 中仅可编辑自己创建的记录 *该用户可编辑全部字段和记录。 *在权限角色 A 中仅可编辑自己创建的记录 *权限角色 B 中仅可编辑单选标签为“任务进行中”的记录 *该用户可编辑自己创建的记录以及单选标签为“任务进行中”的记录。
- **Q：我有可管理权限，在移动端打开多维表格为什么提示无权限？**
  A：请将飞书移动端升级到 V5.7 及以上版本后再次尝试。
- **Q：向高级权限的角色中添加群组时，为什么找不到想要添加的群组？**
  A：这可能是由于你不在群组内。向角色中添加群组时，只能添加当前操作者所在的群组，不在群组内则无法添加。
- **Q：开启多维表格高级权限后，怎样自动将用户添加到高级权限角色中？**
  A：你可以通过以下方式自动将用户添加至高级权限角色： 在多维表格右上角的 分享 面板中，设置多维表格的分享范围和权限，分享范围可选“所在组织”或“互联网获得连接的人”，分享权限可选“可阅读”或“可编辑”。设置后，在该范围内的用户将自动获得高级权限中的阅读者或编辑者角色。 将群组、部门或用户组添加到多维表格高级权限角色中。如果用户属于该群组、部门或用户组，则将自动被添加到该高级权限角色中。
- **Q：有在多维表格新增记录的权限，为什么只能从数据表左上角添加记录，看不到下方的添加记录图标？**
  A：在开启高级权限后，如果数据表设置了分组，由于在分组内新增记录会自动填充分组字段信息，如果用户对分组字段无新增权限，则只能看到顶部的 ⊕ 添加记录，而看不到每个分组左下角的 + 图标。当点击 ⊕ 添加记录 添加记录时，用户可以为有新增权限的字段设置值。
- **Q：当使用多维表格数据表左下角的加号图标添加记录时，为什么不能直接新增一行，而需要在记录详情页填写？**
  A：开启高级权限后，为避免用户在新增记录后因权限限制而无法查看或编辑该记录，新增记录默认需要通过记录详情页填写。 仅以下场景可以直接新增一行： 用户对数据表拥有“可管理”权限。 用户拥有的所有角色都没有设置记录筛选规则，且其中至少一个角色有对数据表的编辑权限。 用户有数据表的“可编辑”权限，且拥有的每个角色都满足以下条件之一： 所有记录和字段可编辑。 记录筛选条件只有一项，为“创建人可编辑”。同时所有字段可编辑。 记录筛选条件有多项，包含“创建人可编辑”，且多项条件之间为“或”（满足任一）的关系。同时所有字段可编辑。
- **Q：如果用户被加入到多维表格的多个高级权限角色中，该用户实际拥有的权限是什么？**
  A：当用户拥有多个高级权限角色时，其实际拥有的权限遵循如下规则： 系统角色中的“所有者”和“管理员”优先级高于其他系统角色和自定义角色。如果将用户 A 同时添加至“管理员”和任何其他角色中，则 A 拥有管理员权限。 自定义角色权限的优先级高于系统角色中的“编辑者”和“阅读者”。如果将用户 A 同时添加至“编辑者”和一个自定义角色中，则用户 A 实际拥有自定义角色的权限。 系统角色中“编辑者”的优先级高于“阅读者”。如果将用户 A 同时添加至“编辑者”和“阅读者”角色中，则 A 拥有编辑者权限。 当用户同时被添加至两个或以上自定义角色时，则获得自己所拥有的所有自定义角色的全部权限。如果用户 A 被添加至自定义角色 1 和角色 2，角色 1 可编辑数据表前三行记录，但不可查看其余记录；角色 2 可查看数据表全部记录，但不可编辑，则用户 A 实际可编辑前三行记录，并可查看全部记录。

- **Q：转发、置顶、Pin、标记、回复、收藏、图片等各类消息可以保留多久？**
  A：消息保留时间与消息类型无关，各类消息保留时间是一致的，仅与你使用的飞书版本有关。即，如果你是个人版及基础版用户，各类消息均只可保留 18 个月；如果你是商业版及企业版用户，各类消息均可永久保留。 对于个人版及基础版用户，超出消息存储时长的消息会被自动清理，清理后你将无法继续在消息界面中查看，也无法搜索到这些消息。仅收藏和标记的消息在超出消息存储时长后仍然可以查看。
- **Q：飞书聊天记录的存储方式是什么？**
  A：飞书桌面端和移动端的所有聊天记录均存储在云端。
- **Q：外部群消息及我与外部联系人的消息是如何存储的？**
  A：外部群及外部联系人的聊天记录也存储在云端，即便外部联系人账号注销也不受影响。
- **Q：会话消息会占用我的云存储空间吗？**
  A：在会话中发送图片、视频、文件、文件夹（以下统称为消息文件）会占用你的云存储空间，直接预览消息文件或下载到本地则不会占用。发送其余类型的消息，如文本消息、云文档等网页链接及表情，不会占用云存储空间。 注：飞书不同版本的云存储空间总量详见下表，具体信息请参考飞书存储空间介绍。 **基础版 *商业版 *企业版 *免费 *标准 *专业 *旗舰 *标准 *专业 *旗舰 认证前：15 GB 认证后：100 GB 1500 GB 5 TB 15 TB 15 TB 15 TB + 购买人数 × 30 GB 15 TB + 购买人数 × 30 GB

  A：计算规则与内部群相同，仅占用发送者的云存储空间。

- **Q：我转发、标记或收藏了某个消息文件，原消息文件被清理，我是否还可以继续查看这个消息文件？**
  A：转发的消息文件仍然可以查看。标记和收藏的消息文件将无法查看。

### 出自《管理员管理邮箱域名常见问题》
原文：https://www.feishu.cn/hc/zh-CN/articles/360048318654-管理员管理邮箱域名常见问题

- **Q：什么是域名？**
  A：域名是一个独立的网络资产，域名可以用于搭建企业的官网，也可作为邮件收发的地址。
- **Q：如何购买域名？**
  A：飞书当前不提供域名购买的服务，推荐前往[火山引擎域名服务](https://www.volcengine.com/activity/domain?utm_campaign=2023&utm_content=domain-service&utm_medium=feishu&utm_source=cuxiao&utm_term=feishu_email)购买域名。你也可以按以下步骤前往特定域名服务商购买域名： 1. 在网页搜索引擎中搜索购买域名。 2. 选择一个域名提供商的网站，在该网站注册账号并登录。 3. 在域名提供商的网站内，将自己想要购买的域名输入到搜索框内，寻找价格合适的域名。 4. 点击购买，完成支付，即可拥有此域名。
- **Q：可以在飞书邮箱中添加多少个域名？**
  A：最多可以添加 100 个主域名，每个主域名可以最多添加 100 个域名别名。
- **Q：为什么无法绑定邮箱域名，提示域名已被其他组织使用？**
  A：可能是因为该域名已被其他组织绑定，一个域名只能绑定到一个组织。请检查是否有其他组织或账户已经绑定了该域名，在相应组织或账户中删除该域名后，再重新绑定。
- **Q：如何删除域名？**
  A：进入飞书管理后台，打开 产品设置 > 邮箱 > 服务管理 > 域名管理，在需要删除的域名行点击 ... > 删除。 通过验证码确认管理员身份。 在确认删除域名的影响后勾选 我已知悉，并手动输入需要删除的域名，最后点击 删除 即可。 注：输入域名时不可直接粘贴。
- **Q：删除域名时会删除哪些数据？**
  A：1. 邮箱地址 删除域名后，域名及其别名（如果有）下所有的成员企业邮箱地址、公共邮箱地址、邮件组地址都将被删除，不可再使用该域名下的企业邮箱、公共邮箱、邮件组收发邮件。 例如：删除域名 example.com 后，成员邮箱 John@example.com 、公共邮箱 hr@example.com 、邮件组 project@example.com 都将被删除。 2. 邮件数据 - 成员邮箱 删除域名后，成员企业邮箱内的邮件数据不会被删除。管理员重新给成员配置企业邮箱地址后，成员就可以查看原邮箱里的数据。 - 公共邮箱 删除域名后，域名下公共邮箱的邮件数据会被清除，且不可恢复。 - 邮件组 邮件组仅用于分发邮件到邮箱，本身不会存储邮件数据。

### 出自《邮箱搬家常见问题》
原文：https://www.feishu.cn/hc/zh-CN/articles/360049067810-邮箱搬家常见问题

- **Q：管理员添加成员并开启邮箱搬家任务后，为什么在成员邮箱搬家列表中找不到某个成员？**
  A：可能是因为该成员已存在于某个域名的搬家任务中。成员只能同时参与一个域名搬家任务，已在搬家任务中的成员无法被添加到其他搬家任务。
- **Q：邮箱搬家时，管理员给成员配置的企业邮箱地址，可以和原邮箱服务的地址不一致吗？**
  A：不可以。新旧邮箱地址不一致时，搬家过程中无法正常匹配。
- **Q：成员在邮箱搬家前已在飞书上绑定过企业邮箱了，绑定时在飞书上收发的邮件数据会迁移吗？**
  A：不会。如果在邮箱迁移前，成员已经先在飞书上绑定过该域名下的企业邮箱，并使用飞书进行收发信，那么在邮箱迁移时原本成员绑定的对应邮箱账号就会解绑，同时邮件数据会被清理。
- **Q：同一域名可以在两个飞书租户中启用企业邮箱吗？**
  A：不可以。一个域名只存在于一个飞书租户中。
- **Q：邮箱搬家后，域名可以保持不变吗？**
  A：可以。邮箱搬家不会改变域名。
- **Q：文件夹里的邮件也能迁移过来吗？**
  A：可以。会按照原本文件夹的结构迁移过来。
- **Q：公共邮箱也能迁移吗？**
  A：可以。邮箱管理员将公共邮箱分配给成员后，该成员开启迁移即可，具体信息请参考企业成员迁移公共邮箱历史邮件。
- **Q：邮箱搬家会影响原邮箱的使用吗？**
  A：不会。搬家期间，不影响原邮箱使用。
- **Q：邮箱搬家可以分批进行吗？**
  A：管理员开启邮箱搬家任务后，可以分批添加需要进行搬家的成员。未加入搬家的成员不会收到通知和打扰。
- **Q：邮箱搬家时，管理员能统一设置成员的企业邮箱密码吗？**
  A：不能。进行邮箱搬家时，成员登录企业邮箱只能使用第三方客户端密码，管理员无法统一设置密码。
- **Q：邮箱搬家时，原邮箱收到异地登录提醒怎么办？**
  A：在邮箱搬家过程中，原邮箱可能会收到一次或多次异地登录的提醒。这是因为邮件搬家引起的，无需处理，忽略即可。 一般情况下，随着用户搬家时间推移，异地登录提醒会变少直到消失。
- **Q：邮箱搬家过程中，成员可以在飞书邮箱收发新邮件吗？**
  A：可以。搬家过程中产生的新邮件也会反向同步回到原邮箱服务中。
- **Q：如果想一直保持原邮箱和飞书邮箱均可同时使用，该怎么操作？**
  A：让邮箱迁移流程长期运行，不要关闭搬家即可。
- **Q：邮箱搬家过程中，成员不断会收到新邮件，成员的邮箱数据是不是永远搬不完？**
  A：不会。新增数据会实时同步到飞书邮箱，只要完成历史数据的迁移即可。
- **Q：成员在邮箱搬家过程中可以修改邮箱密码吗？**
  A：不可以。如果在邮箱搬家过程中成员修改了邮箱密码，会导致搬家失败。如果有不可抗力因素导致修改了原邮箱密码，成员可以在飞书客户端等待一段时间，如果检测到原密码失效，飞书邮箱会提供弹窗让成员重新输入新的邮箱密码。
- **Q：成员可以在邮箱搬家过程中调整文件夹分类吗？**
  A：不建议。在邮箱搬家过程中，尽量不要大规模移动邮件至其他文件夹，避免出现同步问题。
- **Q：在邮箱搬家过程中，有新成员入职怎么办？**
  A：如果新成员需要立刻使用邮箱服务，管理员需要在原企业邮箱后台和飞书管理后台两边都为新成员创建好邮箱。只在飞书为新成员创建企业邮箱，该邮箱无法使用。 如果该用户可以稍晚使用邮箱服务，管理员可以等待邮箱搬家结束，在飞书为该用户配置邮箱地址。
- **Q：在邮箱搬家过程中，有成员离职怎么办？**
  A：需要在原企业邮箱后台和飞书管理后台两边都操作该成员的离职。
- **Q：在开启邮箱搬家后，还需要再添加一名或多名成员至搬家任务中要怎么办？**
  A：如果只是暂停了搬家任务，管理员可以添加搬家成员，稍后再继续进行邮箱搬家任务。如果已经选择结束搬家，则需要创建新的搬家任务。
- **Q：并没有进行邮箱搬家，但是成员的邮箱界面显示有搬家错误怎么办？**
  A：需要管理员打开[飞书管理后台](http://feishu.cn/admin)，点击 产品设置 > 邮箱 > 服务管理 > 域名管理，找到对应的域名，点击域名后方的 继续配置，检查域名的搬家任务是否运行正常。 ![](https://p1-hera.feishucdn.com/tos-cn-i-jbbdkfciu3/41073ccde2ec41db81819644432f48e1~tplv-jbbdkfciu3-image:0:0.image)

  A：刷新一下搬家页面，查看进度是否有更新。通常情况下，邮箱搬家会在 5 分钟后更新进度。如果一直停留在 0%，请[联系客服](https://applink.feishu.cn/client/web_url/open?width=640&height=480&mode=window&url=https%3A%2F%2Flinkchat.feishu.cn%2Fim-linkchat%2Fredirect.html%3Fsource%3D5%26channelId%3D44)。

- **Q：部分邮件搬家失败怎么办？**
  A：需先查看是否为无法进行搬家的邮件。部分邮件格式由于原服务厂商没有提供协议格式，无法迁移到飞书邮箱，具体信息如下： | 类型 | 说明 | | 草稿 | 在草稿箱中的邮件 | | Outlook 组 | 仅对于 Outlook 用户有效，由于Outlook 的特有功能，此类数据无法迁移 | | 系统重名文件夹 | 如果用户自定义文件夹名称为以下名称，则无法迁移： - 收件箱 - 已发送 - 草稿箱 - 垃圾邮件 - 已删除 | | 大邮件 | 单封邮件大小（包括附件）大于 100 MB | | 特殊邮件 | 如特殊格式的广告邮件、本身格式不符合规范的邮件、损坏的邮件 | 如果不属于以上这些邮件类型，但仍然有搬家失败的邮件，请[联系客服](https://applink.feishu.cn/client/web_url/open?width=640&height=480&mode=window&url=https%3A%2F%2Flinkchat.feishu.cn%2Fim-linkchat%2Fredirect.html%3Fsource%3D5%26channelId%3D44)。

## 审批
### 出自《飞书审批常见问题》
原文：https://www.feishu.cn/hc/zh-CN/articles/360045410394-飞书审批常见问题

- **Q：我主动撤回提交的审批后，是否可以修改该审批并重新提交？**
  A：不可以。撤回即意味着该审批流程结束，不支持修改。如有需要，你可以重新发起一个新的审批。 注：你可以在该审批单据页点击 再次提交 快捷修改内容后提交，但是此操作会生成一个新的审批流程。
- **Q：我是审批人，误操作点了“通过”或“拒绝”，该如何处理？**
  A：请参考下文处理。 如果该审批尚未结束，你可以联系当前节点的审批人，将审批退回至你处，你可以重新审批。 如果该审批已经结束，则无法再做修改。建议你联系审批提交人，由其撤销该审批并重新提交。 注：审批是否允许退回、撤销，取决于企业中审批管理员的设置。如果发现操作中没有上述按钮，请联系审批管理员确认。
- **Q：成员如何在飞书中提交离职申请？**
  A：请先向你的企业确认是否是在飞书审批或飞书人事中提交离职申请。 如果是，你可以参考以下内容操作： 在飞书审批中提交： 使用飞书桌面端或移动端，通过工作台或搜索进入审批应用。 在 发起申请 页面，找到 离职 申请。 按要求填写信息后，点击 提交。 在飞书人事中提交： 使用飞书桌面端或移动端，通过工作台或搜索进入飞书人事应用。 在 自助服务 中，找到 申请离职。 按要求填写信息后，点击 提交。
- **Q：如何删除审批应用中的审批单据？**
  A：企业成员无法自行删除，审批管理员可在审批管理后台操作删除。 如果你是企业成员：你无法自行在审批应用中操作删除，你需要联系企业中的审批管理员进行操作。 如果你是审批管理员：你可前往审批管理后台 > 数据管理 > 数据查看 页面，找到所需删除的审批单据，点击 ··· > 删除 操作删除。 *重要： *删除操作不可恢复。删除后，成员便无法查看审批（但管理员仍可在审批管理后台查看与导出）。 *如果删除了已通过的加班审批，所申请的加班数据不会退回，且成员无法再提交同时段的加班审批。 *如果删除的是流程中的审批，该流程也即中断，后续审批人无法继续审批（如果已给审批人推送了审批消息，消息卡片上会显示该审批已删除）。
- **Q：审批流程没有变动，为什么审批单据之前流转给成员甲，现在却没有流转给他或流转给了其他人？**
  A：可能是因为提交人或成员甲的部门/角色发生了变化。企业管理员可以前往飞书管理后台 > 组织架构 查看成员的部门/角色是否发生了变化。
- **Q：管理员在审批管理后台删除了审批，该如何找回？**
  A：删除的审批无法找回。如有需要，你可以重新创建一个审批。
- **Q：管理员如何为审批设置多语言？**
  A：在审批管理后台 > 审批管理 页面，点击某个审批右侧的 设置多语言 图标，点击 编辑 即可对该审批中的表单字段、流程节点等内容设置多语言，还可选择该审批的默认语言。目前支持简体中文、英语、日语等多种语言。 设置完成后，该审批会根据成员使用的飞书显示语言，自动显示对应的语言版本。
- **Q：为什么同一个审批，两个管理员看到审批名称不一样？**
  A：可能这个审批设置了多语言名称，两个管理员在不同系统语言的审批后台看到的名称不一样。
- **Q：为什么同一个审批，成员和管理员看到审批名称不一样？**
  A：可能这个审批设置了多语言名称，成员和管理员若在不同系统语言里，则看到的审批名字不同。例如，管理员在系统语言为英文或者修改了英文的多语言审批名称，则成员需要将系统显示语言切换为英文才能看到管理员修改的名称。
- **Q：审批管理后台支持几种显示语言？**
  A：3 种，支持简体中文、英语、日语。你可以在[审批管理后台](https://www.feishu.cn/approval/admin/approvalList)，点击右上角头像 > 语言 进行切换。 ![](https://p1-hera.feishucdn.com/tos-cn-i-jbbdkfciu3/77cd1ec5a5a040d7aa044d96affe7463~tplv-jbbdkfciu3-image:0:0.image)
- **Q：审批设置了出差控件组，为什么没有关联到成员考勤，成员仍被记录为了考勤异常？**
  A：这种情况下，需要企业中的假勤管理员前往假勤管理后台 > 考勤设置 > 考勤组设置 页面，检查考勤组是否勾选了 出差期间需打卡。如果勾选了此项，则成员在出差审批通过之后，仍需要按照要求打卡，才不会被记录为考勤异常。
- **Q：如何修改报销审批中的货币类型？**
  A：管理员可按以下步骤进行修改： 1. 进入[审批管理后台](https://www.feishu.cn/approval/admin/approvalList) > 审批管理 页面，找到报销审批，进入 表单设计 页面。 2. 点击表单中添加的 金额 控件，在右侧 币种 设置项中修改币种。如果设置了多个币种，成员可在此范围内自选。 注：成员无法自行在报销审批中修改货币类型，只能按照管理员的设置进行选择。 ![](https://p1-hera.feishucdn.com/tos-cn-i-jbbdkfciu3/3b39177dc4804336af2ade10677f2c1e~tplv-jbbdkfciu3-image:0:0.image)
- **Q：审批中的“附件”控件可上传文件的大小和数量是多少？**
  A：单个文件最大 500 MB，最多可上传 30 个文件。
- **Q：审批中的“说明”和“单行文本”控件可输入多少个字符？**
  A：最多 256 个字符。
- **Q：审批中的“图片”控件可上传图片的大小和数量是多少？**
  A：单张图片最大 50 MB，最多可上传 20 张图片。 修改审批流程后，我的飞书客户端怎么还没更新？ 答：你可以尝试以下 2 种方式： 方式 1：找到个人头像，点击后选择 设置 > 内部设置 > 获取配置，随后再次查看客户端内是否已经更新。 方式 2： 重启设备，随后再次尝试客户端内是否已经更新。 如果上述方法还无法解决你的问题，请联系客服。
- **Q：有成员无法使用审批应用怎么办？**
  A：可以尝试以下方式： 方式 1：管理员前往飞书管理后台 > 工作台 > 应用管理，找到审批，检查 应用可用范围 是否包含了该成员。 方式 2：成员在导航栏中点击 图标关闭审批，之后重启飞书，通过工作台或搜索重新进入审批。
- **Q：在审批的数据管理中，如何筛选年份更早的数据？**
  A：先在筛选框中选定一个日期，之后再进行筛选，即可继续往前筛选一年，以此类推（例如：选定了 2023 年，即可继续往前筛选 2022 年，以此类推）。
- **Q：如何下载/导出审批中的附件？**
  A：在飞书审批中打开需下载/导出附件的审批详情，并找到附件，点击附件右侧的 下载 图标，即可下载该附件。 注：如果附件右侧没有 下载 图标，你可以点击该附件打开后，再操作下载或保存。
- **Q：设计审批流程时，组织架构中的“单位”可以设置为审批流程中的提交人、审批人、办理人或抄送人中吗？**
  A：不支持。目前仅支持组织架构中的成员、部门、角色、用户组这 4 种类型。
- **Q：我为什么没有收到审批通过的消息通知？**
  A：如果该审批是由你自己本人审批的，则你不会收到消息通知。如果是由其他人审批的，你可以收到消息通知。
- **Q：为什么离职审批单中的成员姓名看不到了？**
  A：可能是因为管理员将该成员设置为了不可见。管理员可前往飞书管理后台 > 安全合规 > 成员权限 > 组织架构可见范围 中检查设置。
- **Q：审批流程卡在了某位审批人处，但是该审批人没有收到消息提醒，该如何操作？**
  A：请参考以下内容。 - 提交人可进入审批单据，点击 催办 提醒审批人（24 小时内仅可催办 1 次，且此间隔不可更改）。 - 审批人无需等待消息提醒，可自行进入审批应用，在 审批中心 找到该审批，进行处理。 注：审批人可通过搜索找到审批机器人，点击  设置 图标，检查是否勾选了 消息免打扰 等设置。 ![](https://p1-hera.feishucdn.com/tos-cn-i-jbbdkfciu3/a25aa9f5767b4e9d9c726091786bd31e~tplv-jbbdkfciu3-image:0:0.image)
- **Q：审批只能在移动端打开，无法在桌面端打开？**
  A：请进行以下尝试。 尝试获取最新飞书配置并重启飞书：进入飞书桌面端，点击个人头像 > 设置 > 内部设置 > 获取配置，在弹窗中点击 重启。 如果你的飞书不是最新版本，也请升级至最新版本。 ![](https://p1-hera.feishucdn.com/tos-cn-i-jbbdkfciu3/8c7b1878951b44b2b253ee176f70fd5a~tplv-jbbdkfciu3-image:0:0.image)
- **Q：使用催办功能提醒审批人时，所填写的催办理由，仅该审批人可见吗？**
  A：催办理由仅该审批人可见。系统会以消息通知的方式提醒该审批人。
- **Q：为什么成员看到的审批单据，与后台设置的不一致？**
  A：可能是因为某些表单字段未被设置为 可读。管理员可进入该审批的设置页面，在 ③流程设计 中，点击某节点，在该节点的 表单权限 中，检查各表单字段是否勾选了 可读。
- **Q：为什么同一个审批，不同成员看到的表单内容不一样？**
  A：可能是因为出现了同名的审批，管理员可前往审批管理后台检查确认。
- **Q：审批消息卡片是否支持自定义设置消息摘要？**
  A：支持。管理员可进入审批的设置页面，在 ④更多设置 中，找到 审批摘要设置，选择 自定义配置，配置表单中的字段内容作为审批摘要。
- **Q：成员提交了审批，为什么没有按照后台设置的流程进行流转？**
  A：请确认成员提交审批的时间，以及这之后管理员是否修改了审批流程。如果修改了流程，只会对修改之后提交的审批生效，修改之前提交的审批仍按原流程进行流转。
- **Q：审批的编号有什么规律？**
  A：它是根据日期等信息生成的一串编码，在整个企业中是唯一的，不分审批类型。
- **Q：管理员之前对审批设置了显隐，为什么该设置消失了？**
  A：请确认是否有其他管理员修改了设置。
- **Q：是否可以为指定部门设置专属的审批？**
  A：管理员可进入审批的设置页面，在 ①基础信息 中，找到 谁可以提交该审批，设置仅指定部门可以提交该审批。
- **Q：如果审批的提交人存在于多个部门，审批会流转给哪位部门负责人审批？**
  A：如果审批的提交人存在于多个部门，当他在提交审批时，需要手动选择相应部门，审批将按所选部门流转给对应的部门负责人。 注：该选项为系统配置，无法删除和编辑。
- **Q：如果组织架构进行了调整，流程中的审批是由原上级还是新上级审批？**
  A：如果审批已经到达了原上级节点，则由原上级审批；如果还没有到达原上级节点，则会变更成新上级。
- **Q：成员在处理审批单据时，为什么无法点击“通过”、“提交”等按钮？**
  A：可能是因为管理员在审批管理后台删除了该审批，管理员可前往审批管理后台检查。
- **Q：管理员在后台修改了审批的表单、流程等内容，会影响已提交的审批吗？**
  A：不影响。管理员在后台修改了审批的表单、流程等内容，只会对修改之后提交的审批生效，修改之前提交的审批仍按原规则进行。
- **Q：为什么成员无法使用审批应用？**
  A：请进行以下尝试。 尝试获取最新飞书配置并重启飞书：点击个人头像 > 设置 > 内部设置 > 获取配置，在弹窗中点击 重启。 尝试退出登录飞书，再重新登录。 尝试更换网络环境或清空缓存后再试。
- **Q：成员在审批的“联系人”控件中选择联系人时，为什么有时需选择部门，有时则不需要？**
  A：如果选择的联系人存在于多个部门，就会自动带出部门控件，此时需要手动选择部门。
- **Q：管理员在审批管理后台设置审批，是否支持指定时间生效？**
  A：不支持。点击 发布 后，即对新提交的审批生效。
- **Q：审批人在休假、外出等长期不方便处理审批时，可以将审批委托授权给其他成员代为处理吗？**
  A：可以。审批人可以按如下步骤操作委托授权： 使用飞书桌面端进入审批应用，点击右上角   设置 图标。 在委托授权设置中，点击 发起委托。 按需设置代理人、代理时间、代理审批流程等内容，点击 发起委托。 （可选）在委托授权设置中，还可点击 委托记录 或 代理记录 查看相关记录。 注：审批人在委托授权期间仍可自行审批，此时审批人和代理人为或签关系，即任意一人处理即视为完成。

## 飞书OKR
### 出自《飞书OKR 使用常见问题》
原文：https://www.feishu.cn/hc/zh-CN/articles/397323596739-飞书okr-使用常见问题

- **Q：怎么修改飞书OKR 周期长度？**
  A：需要 OKR 管理员或被分配周期设置权限的 OKR 子管理员前往 OKR 设置 > 应用设置 > 周期设置，点击 详情，进入编辑页面进行调整。 注：周期长度修改后，之前生效的周期数据将会保留，可以对旧周期进行 暂不处理、标为失效、隐藏周期 操作，但暂不支持 删除 操作。
- **Q：修改飞书OKR 周期后，产生的旧周期如何处理？**
  A：在修改周期长度后，也可对 冲突周期（管理员在修改周期长度后，造成新旧周期重叠的问题）进行处理。处理方式可以选择 暂不处理、标为失效、隐藏周期，暂不支持 删除 操作。 注：选择 隐藏周期后，对应 OKR 内容不会在页面展示，但数据还会保留；如需找回，可前往 周期设置 页面，查看 历史冲突周期 并进行取消隐藏操作。
- **Q：当前 OKR 中我的直属上级不正确怎么办？**
  A：需要企业管理员或 OKR 管理员进入 飞书管理后台 > 组织架构 > 成员与部门 > 成员，搜索对应员工更正其 直属上级 即可。
- **Q：什么时候会展示新的周期？**
  A：默认在新周期开始前 15 个自然日展示。企业 OKR 管理员可以在配置周期时修改 新周期出现时间，具体信息请参考 OKR 管理员为 OKR 设置多周期的“配置周期”小节。
- **Q：我在飞书管理后台调整了组织架构，为什么在飞书OKR 应用当中没有同步更新？**
  A：一般涉及组织架构变动，需要 1-2 小时后数据才会同步，但若涉及本身有下属的 leader 组织架构变动，数据需要 T+1 才能同步。
- **Q：为什么有团队成员反馈无法进入 OKR 应用？**
  A：管理员需要在飞书管理后台> 工作台 > 应用管理 中找到“飞书OKR”应用，启用该功能，并配置 应用可用范围，确保相关成员在可用范围内。
- **Q：什么是年度 OKR？**
  A：年度 OKR 是以年为周期而制定的 OKR，组织可以围绕着这个目标来进行整体的年度工作规划，填写方式和自定义周期的 OKR 相同。你可以在 周期设置 页面，开启 或者 关闭 年度 OKR。
- **Q：为什么我的 OKR 页面只有我的 OKR 和对齐视图，而没有数据看板？**
  A：数据看板仅管理者（拥有直属下级的人员）可见。如果你是有直属下级的管理人员，但是无法看到数据看板，是因为当前的团队组织架构配置不全。[请联系所在企业的企业管理员](https://www.feishu.cn/hc/zh-CN/articles/360049067822-%E7%AE%A1%E7%90%86%E5%91%98%E5%92%8C%E7%AE%A1%E7%90%86%E5%91%98%E8%A7%92%E8%89%B2%E4%BB%8B%E7%BB%8D#tabs0|lineguid-Y7FNY)或 OKR 管理员在 OKR 管理后台进行配置，确保批量导入员工信息时，直属上级字段信息完整。
- **Q：为什么我的 O 无法设置对齐？**
  A：请先确认你想对齐的人员的 OKR 是否已填写。若未填写，则无法对齐该人员的 OKR。
- **Q：KR 之间可以对齐吗？**
  A：不支持 KR 之间对齐，仅支持 O 之间的对齐。
- **Q：是否可以直接对 O 进行打分？**
  A：不行。目前不支持对 O 直接打分，支持对 KR 进行打分，O 的分值为 KR 分值的加权平均分。
- **Q：我可以查看其他部门成员的 OKR 吗？**
  A：取决于管理员在管理后台的“修改企业默认权限”模块中对该部门成员 OKR 的可见范围配置。如果你有权查看该部门成员的 OKR，在 OKR 页面左侧的列表中搜索员工姓名，即可查看对方的 OKR。具体信息请参考[飞书OKR 管理员操作手册](https://www.feishu.cn/hc/zh-CN/articles/360044794554-%E9%A3%9E%E4%B9%A6okr-%E7%AE%A1%E7%90%86%E5%91%98%E6%93%8D%E4%BD%9C%E6%89%8B%E5%86%8C) 。
- **Q：为什么我有数据看板但是没有发送提醒的按钮？**
  A：只有 OKR 管理员和应用管理员有“发送提醒”的功能权限。
- **Q：如何查看历史版本？**
  A：在 OKR 页面点击右上角的 ... 图标，在里面可以找到 历史版本 的入口，点击即可进入。历史版本仅自己、所在汇报线上的上级和管理员可查看。
- **Q：什么情况下会产生历史版本？**
  A：进行过 OKR 修改并且发布了修改，此时会产生历史版本。 注：每天最多只会产生一个历史版本。即一天内发生过多次修改，只会记录当天最后一次修改的版本。且 OKR 历史版本仅记录 OKR 内容的变化，不记录顺序、进度、权重、打分。
- **Q：KR 有篇幅限制吗？**
  A：有，KR 的字符上限是 999，目前不支持扩容。如果内容较多可以写在文档中，然后将文档链接粘贴在 KR 中。
- **Q：如何修改周期复盘文档的权限？**
  A：和修改其他云文档的权限方式一致，具体信息请参考分享云文档。
- **Q：管理员对齐视图为什么没有内容？**
  A：管理员对齐视图中仅包含其管理范围内 没有汇报关系的人员（即在组织架构配置时，未配置直属上级的人员），请确保符合该条件的人员已填写了 OKR 内容。如未填写，则管理员的对齐视图中也不会有内容。
- **Q：谁可以查看数据/不同角色的数据权限？**
  A：OKR 管理员/子管理员/上级（有下级的人员）。 管理员：数据看板+数据详情，查看和导出所有人员的数据。 子管理员：设定范围内的数据 上级：数据看板，查看全部下级的相关数据。
- **Q：OKR 提供 API 接口吗？**
  A：仅企业版可以调用飞书开放平台上 OKR 相关的 Open API：OKR 开发指南 - 服务端文档 - 开发文档 - 飞书开放平台

## 视频会议
### 出自《视频会议热门问题》
原文：https://www.feishu.cn/hc/zh-CN/articles/188364995423-视频会议热门问题

- **Q：会议过程是否加密？**
  A：会议的整个过程是加密的，飞书不会对语音或视频通话过程中的内容做记录，只会从中存储一些元数据，包括会议主题、发起者、参会人员、会议结束时间、成员加入和离开会议的时间等信息。
- **Q：会议链接多久会失效？**
  A：- 普通的非重复性日程、网络研讨会（Webinar）日程：日程结束时间 30 天内，会议链接及会议号仍然有效，该日程可以正常发起视频会议。日程结束时间 30 天后，会议链接及会议号会失效，该日程不能再发起视频会议。 - 重复性（循环）日程： 若重复性日程设定了截止日期，则会议链接及会议号会在截止日期的 30 天后失效。 若重复性日程没有设定截止日期，会议链接及会议号一般在最后一次会议日程结束的 365 天后失效。 若某个重复性日程会议一直未被发起，则会议链接及会议号将在日程创建日期的 365 天后失效。
- **Q：重复性日程的会议 ID 是固定的吗？什么时候会失效？**
  A：- 对于重复性日程，所有日程会对应同一个会议 ID 和会议链接。 - 若重复性日程有设定截止日期，则会议 ID 会在截止日期的 30 天后失效。若重复性日程没有设定截止日期，会议 ID 一般在最后一次会议日程结束的 365 天后失效。若某个重复性日程会议一直未被发起，则会议 ID 将在日程创建日期的 365 天后失效。
- **Q：如何防止参会人在组织者入会前发起视频会议？**
  A：会议组织者进入日历页面创建日程后，点击 视频会议 选项右侧的 会议设置，取消勾选 允许日程参与者发起会议，则仅有日程的组织者可以开启会议。在会议尚未开始时，其他参会人加入会议画面将提示 请稍候，组织者尚未开启会议。待组织者发起会议后，正在等候且有入会权限的参会人将会自动入会。 有关视频会议设置的具体信息，请参考[在日程卡片提前进行视频会议设置](https://www.feishu.cn/hc/zh-CN/articles/360049067940#magicdomid-1_10)。
- **Q：如何查看错过的会议呼叫？**
  A：点击导航栏 视频会议，进入导航栏视频会议界面。历史记录 中未接听的通话或会议呼叫会显示为红色。 你可以点击该条记录查看详情。
- **Q：如何查看一场会议的参会人数限制？**
  A：会议中，点击视频会议界面上方的 会议信息，在 会议权益 处可查看本场会议的参会人数限制。
- **Q：一个小时的视频会议所产生的妙记文件有多大？**
  A：时长一小时的会议录制文件大小视具体会议内容而定，会受会议中视频内容和共享内容等因素的影响。通常情况下，若会中有共享内容时，如共享幻灯片，一小时的妙记文件大约为 100-200 MB；若整场会议开启了摄像头，一小时的妙记文件约为 300-400 MB。
- **Q：视频会议的延迟较高怎么办？**
  A：会议延迟较高可能与你正在连接的网络环境有关。建议尝试切换多种网络连接方式，如切换其他 Wi-Fi、手机热点或使用网线等，选择延迟较低的网络环境接入会议。
- **Q：网络环境差或设备电量低时，如何流畅使用视频会议？**
  A：建议参会人调整视频会议性能模式，以获得稳定的会议体验。在会议中，参会人可点击视频会议工具栏中的 ··· > 设置 > 常规，在 性能模式 中选择 节能，降低视频画质，延长电池续航并节省流量；或选择 仅保留音频和共享，停止接收视频并关闭摄像头，仅保留共享，保障会议流畅。
- **Q：视频会议主页中的会议历史记录可以删除吗？**
  A：会议历史记录无法删除。
- **Q：如何取消/退出已预约的会议？**
  A：参考以下内容。 若需取消自己预约的会议日程，可在日历中找到该日程，点击日程卡片上方的 删除日程，即可取消该会议。 若不想参与他人预约的会议，可点击日程卡片上方的 退出日程，退出该会议。
- **Q：已结束的视频会议，有历史记录，为什么没有会议纪要？**
  A：以下 2 种情况会在历史记录中生成会议纪要，请检查确认： 在日程中创建了会议纪要，或关联了文档作为会议纪要。具体信息请参考在日程中创建会议纪要。 在会议中开启了 AI 总结 后，会议结束生成了智能纪要文档。具体信息请参考使用智能会议纪要功能。

## 账号与设置
### 出自《清理缓存和系统重置常见问题》
原文：https://www.feishu.cn/hc/zh-CN/articles/399507903065-清理缓存和系统重置常见问题

- **Q：什么情况下需要清理飞书客户端的缓存？**
  A：遇到本地空间不足而无法发送图片、无法下载附件等情况时，你可以选择清理缓存。在飞书客户端点击个人头像，选择 设置 > 通用，找到并点击 清理缓存。
- **Q：什么情况下需要重置飞书的设置项？**
  A：飞书桌面端出现异常时，你可以重置设置项。此操作会还原所有设置，清理飞书所有本地缓存数据并修复异常。 在飞书桌面端点击个人头像，选择 设置 > 系统诊断，点击 重置设置项 后的 重置 即可。若重置后仍存在异常，可联系客服。 注：移动端不支持重置设置项。
- **Q：清理飞书客户端缓存后，聊天记录和在线文档会被一起清除吗？**
  A：不会。聊天记录及在线文档均储存在云端。清理缓存后，本地缓存的图片、视频等内容将被清理，储存在云端的内容不会被一起清除。
- **Q：重置飞书的设置项后，重要文件会丢失吗？**
  A：本地内容和数据（如消息草稿）将被清除，但聊天记录和文件仍保留在云端，可随时重新下载。

- **Q：什么是飞书的 Mac App Store 版本？**
  A：Mac App Store 版本是指在 Mac 应用商店（Mac App Store）单独上架的飞书应用。和 iOS 版本类似，在 Mac 应用商店上架需遵循 Apple 制定的更严格的开发要求和审核规则，因此和官网下载的版本相比，Mac App Store 版本对少数功能做了改造和下线处理。 即便如此，绝大部分功能还是都得到了保留，因此 Mac App Store 版本和官网版本的区别并不大，核心使用场景的体验是一致的。
- **Q：Mac App Store 版本和官网下载的飞书版本有什么区别？**
  A：受 Mac 应用商店的审核要求限制，Mac App Store 版本存在以下功能差异点： *差异功能 官网版本 Mac App Store 版本 应用内升级 可自动下载新版本，重启完成版本升级。 不支持自动下载更新，依赖 Mac 应用商店进行升级。应用商店支持自动更新。 官网下载链接 在 设置 > 关于飞书 处展示 获取最新客户端 跳转链接。 不显示 获取最新客户端 跳转链接。 提取图片中文字 截图或查看图片时，有 提取文字 选项。 截图或查看图片时，没有 提取文字 选项。 修改下载文件夹 在 设置 > 通用 中包含 文件保存位置 选项，支持修改文件保存位置。 不显示“文件保存位置”选项，默认下载到系统的“下载”文件夹中。 修改默认浏览器 在 设置 > 效率 中包含 默认浏览器 选项，支持修改默认打开网页链接的浏览器。 不显示“默认浏览器”选项，只会调用系统默认浏览器。 视频会议标注功能 在视频会议共享桌面时，支持在桌面上使用“标注”功能进行绘图共享。 在视频会议共享桌面时，不支持“标注”功能。 视频会议共享电脑音频 在视频会议共享桌面时，支持共享电脑音频。 不支持共享电脑音频功能。
- **Q：我们更推荐从哪里下载飞书？**
  A：考虑到官网版本更新频率更快、功能最为全面，建议优先到官网下载。

- **Q：成员如何联系假勤管理员？**
  A：如果已加入考勤组，可在移动端的“打卡”页面右上角点击 考勤规则，然后将页面下滑到底部可以在“考勤管理员” 部分查看你对应的假勤管理员。 如果未加入考勤组，可在移动端的“打卡”页面右上角点击 考勤规则 > 联系管理员，点击列表中的某个管理员即可向该管理员发起会话，你也可以询问同事或上级领导等相关人员。 注：如果你的移动端“打卡”页面右上角不显示 考勤规则，可能是因为假勤管理员设置了成员无法查看考勤规则。在这种情况下，你需要通过询问同事或上级领导联系假勤管理员。
- **Q：管理员设置了工作日允许加班，为什么成员在申请加班时显示加班时长为 0？**
  A：只有工作时间以外的时间段才会计加班时长。因此，请管理员进行以下确认： 确认工作时间设置正常：确认已将该成员添加进相应的考勤组，并检查对应的工作日、班次、节假日等设置（如果是排班制考勤组，管理员还需进入排班页面查看是否已为该成员排班）。 注：如果是自由班制，还需检查打卡时段设置，只有打卡时段以外的时间才会计加班时长。 确认成员的加班时间段正常：检查该成员申请加班的时间段是否误选了工作时间。只有工作时间以外的时间段才会计加班时长。
- **Q：成员的加班申请填写错了，该如何撤销或修改？**
  A：当成员满足所设置的规则时，成员可以在加班单据中，点击底部相关按钮（或点击 ··· 更多 找到相关按钮）进行操作。 注： 成员能否撤销或修改，取决于审批管理员在后台的规则设置。 如果是审批中的加班申请，也可以先由审批人操作拒绝，提交人再重新提交。
- **Q：如何修改补卡、请假、加班、换班等申请的表单、审批人、流程等内容？**
  A：管理员可前往审批管理后台修改： 进入审批管理后台 > 审批管理 页面，找到想要修改的审批，点击编辑图标进入编辑页面。 在编辑页面中，按需进行相关修改。其中： 在 表单设计 页面：可以通过编辑控件或控件组的方式，对表单内容进行修改。但请注意，控件组会与飞书假勤相关联，因此表单中原先添加的控件组不可删除。 在 流程设计 页面：可以修改审批的流程、审批人等内容。 有关如何编辑审批的具体信息，请参考管理员快速上手审批管理。
- **Q：由假勤提供的换班审批，其设置为什么是“均不可提交”，且无法修改？**
  A：请进行以下检查或尝试。 假勤管理员进入假勤管理后台 > 管理员 > 应用配置 页面，在 申请设置 项中点击  编辑 图标，检查换班申请的启用状态是否开启。 审批管理员可尝试在审批管理后台重新创建一个换班审批。请注意，在 ②表单设计 中需使用换班控件组，该审批才可与假勤系统关联。
- **Q：成员离职后，管理员还能查看其之前的考勤数据吗？**
  A：能。管理员可以在以下 2 处查看： 在假勤管理后台的报表页面，添加相关筛选（例如：人员类型、离职日期等）进行查看。 在假勤管理后台的原始记录页面，筛选离职人员进行查看。
- **Q：支持设置休息日禁止打卡吗？**

- **Q：成员或非管理员如何下载自己的考勤统计数据？**
  A：成员或非管理员只能查看自己的考勤数据，无法下载。
- **Q：管理员修改考勤组、假期、加班规则后，为什么之前的数据没有变化？**
  A：管理员在假勤管理后台修改设置后，仅影响修改之后新产生的打卡、请假、加班等数据。修改规则之前产生的历史数据不会受到影响。
- **Q：如何将假勤管理后台、打卡应用、打卡 APP 的界面语言设置成英文、日文等其他语言？**
  A：假勤管理后台：假勤管理员在页面右上角找到并点击头像，点击 语言，在浮现的列表中选择所需语言即可。 移动端假勤打卡应用：成员在飞书中找到并点击个人头像，然后选择 设置 > 通用 > 显示语言 更换显示语言。具体信息请参考调整显示语言。
- **Q：管理员如何取消考勤？**
  A：如需取消某一位成员的考勤，将该成员从考勤组成员中删除即可。 如需取消整个考勤组，删除考勤组即可。删除考勤组之后该考勤组的成员就无需再打卡，即取消了考勤。
- **Q：成员提交了出差或外出的审批流程，为什么假勤系统仍然提示需要打卡，未打卡会显示异常？**
  A：可能有以下原因。 该成员所在的考勤组设置了出差或外出仍需打卡，具体信息请参考管理员设置考勤组。 该成员提交的出差或外出申请未审批或被拒绝。只有审批通过后，考勤系统才会视为该成员无需打卡。 出差或外出申请未覆盖需打卡时段，常见于自由班次考勤组。例如，需打卡时段为 09:00 至 18:00，但申请的出差或外出时段为 10:00 至 12:00。
- **Q：管理员如何关闭飞书假勤？**
  A：管理员进入 飞书管理后台 > 工作台 > 应用管理，进入 假勤 应用，点击 已启用 右侧的开关并在弹窗中点击 停用 即可。

## 日历
### 出自《日历离职相关问题汇总》
原文：https://www.feishu.cn/hc/zh-CN/articles/091324689449-日历离职相关问题汇总

- **Q：如何删除已离职员工建立的日程？**
  A：离职后，属于该员工的日程将转移给管理员指定人员或离职人直属上级，新的日程所有者可以删除日程。其他日程参与者可以主动退出日程。
- **Q：管理员将离职员工的未来日程转移给其他成员，需要注意什么？**
  A：需留意以下两种日程情况 - 系统仅转移日程组织者为离职成员的未来日程，历史日程会被永久删除；但如果该未来日程是私密日程或没有参与者，也会被永久删除。 - 如离职员工创建的公共日历为私密、没有未来日程、没有订阅者，将被永久删除。但如果该公共日历有在职的管理员，将不会被删除。
- **Q：离职员工的日程及会议室资源如何有效处理？**
  A：在操作员工离职时，管理员可以进入[管理后台](https://feishu.cn/admin)，选择转移离职员工的未来日程资源到资源接收人或者直接删除。具体可参考[管理员操作成员离职及转移数据](https://www.feishu.cn/hc/zh-CN/articles/360043223853)。资源接收人的默认选项是离职员工的直属上级，若资源接收人离职，则离职员工的资源将自动删除，不再继续转移。 例如：A 的资源接收人为 B，B 的资源接收人为 C，A 离职后，资源将自动转移至 B，若 B 离职，则 B 的资源将自动转移至 C，但 A 的资源将自动删除，不会跟随 B 的资源一起转移至 C。 - 如果选择 删除 离职员工的未来日程资源，将删除该用户拥有的所有未来日程资源（包括释放已预定的会议室资源），未来日程资源删除后不可恢复，请谨慎操作。 - 如果选择将离职员工的未来日程资源 转移给其他用户 ，资源接收人会收到日历助手推送的成员日历交接提醒，并可对其进行后续设置。
- **Q：资源接收人收到日历助手推送的“成员日历交接提醒”后，可以对该日历进行哪些操作？**
  A：收到日历助手推送的成员日历交接提醒卡片后，资源接收人可以在“我的日历”中发现离职员工的日历，并进行日历 权限设置，包括： - 设置日历公开范围，选项包括：私密、仅显示忙碌或公开。 - 为日历添加共享日历成员，并给予其对应权限。 - 删除日历，此操作是永久删除，请谨慎对待。 注：在未收到“日历助手”推送的成员日历交接提醒卡片前查看离职员工的日历，可能会出现报错提示“没有权限编辑此日历”。
- **Q：资源接收人收到日历助手推送的“成员日历交接提醒”后，可以对离职员工创建的未来日程进行哪些操作？**
  A：资源接收人可以作为新的组织者，在离职员工的日历上对具体日程信息进行 编辑、转发、删除、转让日程 等具体操作。
- **Q：如果提前订阅过离职员工的日历，在对方离职后，还能够继续在日历的订阅列表里查看该员工的日程吗？**
  A：当员工离职后，在日历的订阅列表里无法继续看到离职员工的日历和日程信息，需联系资源接收人再次为你添加订阅权限。
- **Q：如果离职员工创建的未来日程中添加了会议室，是否会在其离职后自动释放？**
  A：离职员工创建的未来日程中如果添加了会议室，不会在其离职后自动释放，该会议室资源会同日程信息一并转移到资源接收人。
- **Q：当转移员工的未来日程资源到资源接收人以后，这些日程信息会有什么变化？**
  A：- 离职员工创建的未来日程中，组织者将更新为资源接收人，如资源接收人过去不在这个日程中，则右侧标志为“不参与”。 - 日程底部会提示这个日程由离职员工创建，右侧标志为“已离职”。
- **Q：无法编辑离职员工创建的日程怎么办？**
  A：若离职员工的日程资源已转移给了新的资源接收人，但接收人仍无法编辑日程，可参考下列步骤解决问题： 资源接收人点击飞书客户端导航栏中的 日历，进入日历界面。 在日历侧边栏的搜索框中搜索离职员工姓名，点击 添加到我订阅的 图标，订阅该离职员工的日历。 在日历侧边栏中，先暂时把其他已经订阅的日历全部“取消订阅”，只保留订阅该离职员工的日历。 尝试编辑此前无法编辑的日程。 编辑完成后可再次重新订阅之前已取消订阅的其他日历。 若以上步骤无法解决你的问题，请联系客服。

### 出自《Exchange Online 绑定和搬家协议切换到 Graph API 说明》

- **Q：什么是邮箱绑定模式？**
  A：通过在飞书邮箱上绑定其他企业邮箱账号绑定了 Exchange Online（Microsoft 365 国际版、世纪互联）的账号，属于绑定模式。
- **Q：什么是邮箱搬家模式？**
  A：通过管理员将 Microsoft 365 或本地部署 Exchange 邮箱迁移至飞书邮箱对接 Exchange Online（Microsoft 365 国际版、世纪互联）进行数据同步的账号，属于搬家模式。
- **Q：怎么判断自己是什么邮箱模式？**
  A：联系管理员确认，或者自己点击飞书头像，进入 设置 > 邮箱 > 账号 查看。如果旁边显示 解绑 按钮，说明是绑定模式；如果账号未显示 解绑 按钮，则属于搬家模式。
- **Q：EWS 跟 Graph API 有什么区别，对邮箱数据同步有影响吗？**
  A：在 Office365 国际版下 EWS 和 Graph API 没区别。由于管理“标签”相关的 API 在世纪互联中不支持，只有当邮件选择标签后，才会通过“邮件”的同步在 Exchange 创建标签。
- **Q：切换到 Graph API 后，管理员通过邮箱权限验证申请时，会授予飞书哪些权限点，有枚举吗？**
  A：绑定模式需要以下权限：offline_access，Mail.ReadWrite，Mail.Send，MailboxSettings.ReadWrite，User.Read，email，openid。搬家模式需要以下权限：Mail.ReadWrite，Mail.Send，MailboxSettings.ReadWrite，User.Read.All。
